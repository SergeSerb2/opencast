# Code of conduct

OpenCast follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work.
Harassment, insults, and personal attacks are not welcome in issues, pull requests,
or any other project space.

To report a problem, use
[GitHub's private reporting](https://github.com/SergeSerb2/opencast/security/advisories/new)
and say that it is a conduct report, or contact the maintainer through their GitHub
profile. Reports are kept confidential.
